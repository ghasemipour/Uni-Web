## سؤال اول: Merge و Rebase

merge:

تغییرات یک برنچ را با برنچ فعلی ادغام میکند، بدون اینکه تاریخچه کامیت های موجود را تغییر دهد. اگر امکان ادغام سریع وجود نداشته باشد،، معمولا یک مرج کامیت ایجاد میکند. موقعیت استفاده: هنگام ادغام برنچ یک فیچر در برنچ اصلی، چون تاریخچه کامیت ها هم حفظ میشه.

rebase:

کامیت های یک برنچ را روی آخرین کامیت های برنچ دیگر بازسازی میکند. درنتیجه تاریخچه معمولا خطی تر میشود، اما شناسه کامیت های بازسازی شذه تغییر میکند. موقعیت استفاده: هنگام بروزرسانی برنچ اصلی با تغییرات جدید چون تاریخچه مرتب میشود و از مرج کامیت غیرضروری جلوگیری میشود.

در کل merge  برای ادغام برنچ های مشترک مناسب تر و rebase برای مرتب سازی تاریخچه برنچ شخصی.
